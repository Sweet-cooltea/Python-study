4. 数字运算符及运用
'''
符号	含义
 ‘+	’ 加法
 ‘-	’ 减法
 ‘*	’ 乘法
 ‘/	’ 除法（结果为小数）
 ‘//’ 整除，只保留整数部分
 ‘%’ 取余数
 ‘**’ 幂运算（次方）
'''
a = 10
b = 3
print("a + b =", a + b)   # 加法
print("a - b =", a - b)   # 减法
print("a * b =", a * b)   # 乘法
print("a / b =", a / b)   # 除法，结果是小数
print("a // b =", a // b) # 地板除（取整数部分，向下取整）
print("a % b =", a % b)   # 取余数
print("a ** b =", a ** b) # 幂运算，a的b次方 10³=1000
input输入用法，input是字符串类型，如需参与数字计算，比如强转为数字类型
